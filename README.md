# wifi-projekt
Jednoduchý Bash script, který vypíše okolní wifi sítě a uloží je do souboru.
## Co skript dělá
- zapíše aktuální čas
- vypíše dostupné wifi sítě (název, síla signálu, kanál, zabezpečení),
- uloží výsledek do souboru wifi.log

  ## Jak ho spustit
  bash wifi.sh
  ## Co jsem zjistil
  - moje síť má signál 99 (měřené v místnosti jako router)
  - Vysílá na kanálu 112
  - kolem mě se nachází 20 sítí
    
    ## Co jsem se naučil
    - základy Bash a práce s terminálem v Linuxu
    - jak číst výpis wifi sítí (signál, kanál, zabezpečení)
      Skript pouze vypisuje sítě v okolí, k žádné se nepřipojuji.
